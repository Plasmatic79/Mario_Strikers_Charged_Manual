# How Does This Randomizer Work?

This is a randomizer for Mario Strikers Charged. It includes settings to randomize your access to characters, abilities, and locations in the game. Because this is a Manual, you will be required to self-restrict these items - there is no mod to do it for you. Below is a detailed description of the items in the game and what they unlock.

```
Progressive Cup: 3 instances of Progressive Cup exist in the randomizer. The first unlocks Fire cup, the second Crystal Cup, and the third Striker Cup.
Progressive CPU Difficulty (Domination Mode): Each successive instance unlocks the next higher CPU difficulty. Rookie is always unlocked.
Progressive Striker Challenge Difficulty: Each successive instance unlocks the next higher difficulty of Striker challenges. Rookie is always unlocked.
Progressive Charge: An ability unlock. The first unlocks Charge, the second Skillshot, and the third Megastrike.
Any 'Ability': Unlocks the relevant ability. Abilities include Hit, Slide Tackle, Lob, Items, and Deke.
Any 'Captain': Unlocks the relevant captain.
Any 'Sidekick': Unlocks one use of the relevant sidekick. There are three of each sidekick in the randomizer. If you only have one Boo item, you can only use one Boo on your team.
Any 'Cheat': Unlocks the relevant cheat for use in Domination Mode.
```

At the start of this randomizer, you have access to Rookie difficulty matches in Domination Mode and Rookie difficulty Striker Challenges. Everything else will need to be unlocked.
